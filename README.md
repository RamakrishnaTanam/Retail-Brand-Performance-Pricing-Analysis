# Retail Brand Performance & Pricing Analytics(Data Source : Microsoft Azure SQL Database)

**Azure SQL Database | SQL | Power BI | DAX | Power BI Service**

An end-to-end retail analytics project analyzing men's T-shirt brands to understand **pricing, discounts, product variety, and profitability**. Data was loaded and cleaned in Azure SQL, analyzed in Power BI, and published through Power BI Service.

## 📊 Dashboard


## 🎯 Business Objectives

- Identify brands with the highest average discounts.
- Compare brand-level average profitability.
- Find brands with the highest product variety.
- Analyze average selling prices across brands.
- Identify the lowest-profit brands.
- Convert raw product data into actionable business insights.

## 🔄 End-to-End Workflow

**Dataset → Azure SQL Database → SQL Cleaning → Power BI → Data Preparation → DAX → Dashboard → Power BI Service**

## 🛠️ Skills Demonstrated

- **SQL:** Data loading, cleaning, aggregation and analysis
- **Azure SQL Database:** Cloud data storage and querying
- **Power BI:** Data connection, modeling and interactive reporting
- **DAX:** Discount %, Profit %, Cost Price and analytical calculations
- **Data Analysis:** Brand, pricing, discount and profitability analysis
- **Data Visualization:** Bar, Donut, Ribbon and Area charts
- **Power BI Service:** Publishing and report sharing

## 📌 Key Metrics & Analysis

| Analysis | Purpose |
|---|---|
| Average Discount % | Compare discount strategies by brand |
| Average Profit % | Evaluate brand profitability |
| Product Variety | Identify brands with the widest assortment |
| Average Sale Price | Compare brand pricing levels |
| Bottom 5 Profit % | Identify low-profit brands |

## 🗂️ Dataset

The primary table contains:

`Brand` · `Title` · `Cost Price` · `Marked Price` · `Sale Price` · `Discount Percentage` · `Profit %`


## 💡 Business Value

The dashboard helps compare brand-level pricing and discount strategies, identify profitable and low-performing brands, and support data-driven decisions around **pricing, product assortment and profitability**.
